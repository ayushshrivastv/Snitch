# Payment method artwork

Downloaded from official brand sources on 2026-09-11. Artwork is stored unchanged.

- `ethereum.svg`: Ethereum purple diamond from [Ethereum brand assets](https://ethereum.org/assets/), [original SVG](https://ethereum.org/images/assets/svgs/eth-diamond-purple.svg).
- `base.svg`: `1_Base Brand Assets/The Square/Base_square_blue.svg` from the [official Base brand kit](https://brand.base.org/base-brand.zip), linked by [Base core identifiers](https://brand.base.org/core-identifiers). The SVG's `blue` fill is Base Blue (`#0000ff`).

Use these as network/payment method identifiers and preserve their original proportions and colors. Network labels in the app distinguish Ethereum Sepolia from Base Sepolia; the artwork itself does not imply checkout support.
